# Real Estate Management System

## 📌 Project Overview

The **Real Estate Management System** is a web-based application designed to simplify the management and browsing of real estate properties. The system allows users to explore available properties, view property details, and manage property-related activities through an easy-to-use interface.

The project also provides administrative functionality for managing properties and users.

## 🚀 Features

* User Registration and Login
* Browse Available Properties
* View Detailed Property Information
* Property Booking/Management
* User Management
* Admin Management
* Property Listing Management
* Responsive Web Interface
* MySQL Database Integration

## 🛠️ Technologies Used

* **PHP** – Backend development
* **MySQL** – Database management
* **HTML** – Website structure
* **CSS** – Styling and layout
* **JavaScript** – Client-side functionality
* **XAMPP** – Local development server

## ⚙️ Installation & Setup

### 1. Install XAMPP

Install XAMPP and start:

* Apache
* MySQL

### 2. Clone the Repository

```bash
git clone https://github.com/your-username/real-estate-management-system.git
```

### 3. Move the Project

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### 4. Setup the Database

1. Open:

```text
http://localhost/phpmyadmin/
```

2. Create a new MySQL database.
3. Import the project's `.sql` database file.
4. Update the database connection settings in the PHP configuration file if required.

### 5. Run the Project

Open your browser and visit:

```text
http://localhost/my_project2/real_estate_management_system/index.php
```
